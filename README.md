# Anant Tech Infra

Responsive industrial website designed and developed by [Wixgo](https://www.wixgo.in/).

## Stack
HTML, CSS and vanilla JavaScript. No build step or database.

## Run locally
Run `python -m http.server 8000` in this directory and open http://localhost:8000.

## Deploy
Deploy this directory as a static website with no build command.

## Features
Responsive navigation, six services, quality and infrastructure sections, ISO certificate viewer, project process, and contact information. The enquiry form opens an email draft; it does not send email through a backend.
